# GDSC Hack Day 2k22 — Solutions

This folder contains my notes, solution files, and supporting artifacts for challenges from the GDSC Hack Day 2022 mini CTF.

## Challenge categories

| Category | Challenges |
| --- | --- |
| Cryptography (`cypto/`) | `base`, `SimpleXor`, `Weird_sequence`, `war` |
| Linux (`linux/`) | `flag-in-a-file`, `hiden file` |
| Miscellaneous (`misc/`) | `flag_reader`, `int_of`, `memedit`, `meta`, `steghide` |
| Programming (`programming/`) | `UnzipMe` |
| Reverse engineering (`reverse/`) | `baby-c-1`, `baby-c-2` |
| Web (`web/`) | `Piece_of_cake`, `Srcode`, `Srcode2`, `cookies`, `jokes` |

## Using these files

Open a challenge's folder to find its `solution` notes and any related source files or challenge artifacts. Some folders contain scripts or compiled binaries; these are specific to their challenge and may need the original challenge environment to run.
